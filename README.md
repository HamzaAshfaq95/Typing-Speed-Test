# Typing Speed Test (Tkinter)

A simple, offline **typing speed test** desktop application built with Python's **`tkinter`**.

Type the displayed pangram-style text as fast and accurately as possible in 5 seconds.  
At the end, you'll see your:

- **WPM** (Words Per Minute – correct words only)
- **CPM** (Correct Characters Per Minute – correct characters excluding spaces)

## Features

- Fixed 5-second countdown timer
- Classic test text (pangram + extra sentences)
- Real-time character & word accuracy comparison
- Clean, retro Courier font interface
- Start & Reset buttons
- Prevents timer from starting multiple times
- Disables input field during countdown (after start)
